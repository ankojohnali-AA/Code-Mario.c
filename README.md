# Code-Mario.c

A C implementation of the classic Mario game.

## Description

This project recreates the iconic Mario platformer game in C, featuring pixel-perfect gameplay, classic level design, and retro aesthetics.

## Features

- Classic Mario platformer mechanics
- Multiple levels
- Enemy AI
- Power-ups and collectibles
- Score tracking

## Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/ankojohnali-AA/Code-Mario.c.git
   cd Code-Mario.c
   ```

2. Compile the project:
   ```bash
   gcc -o mario main.c
   ```

3. Run the game:
   ```bash
   ./mario
   ```

## How to Play

- Use **Arrow Keys** or **WASD** to move Mario left and right
- Press **Space** to jump
- Collect coins and avoid enemies
- Reach the end of each level to advance
- Defeat Bowser to win!

## Controls

| Key | Action |
|-----|--------|
| ← / A | Move Left |
| → / D | Move Right |
| Space | Jump |
| ESC | Quit |

## Project Structure

```
Code-Mario.c/
├── main.c          # Main game loop
├── mario.h         # Mario game header
├── levels/         # Level data files
└── assets/         # Game graphics and sprites
```

## Requirements

- GCC compiler or compatible C compiler
- Standard C library (libc)
